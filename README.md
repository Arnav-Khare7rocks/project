# Task Management App

This is a simple, command-line Task Management Application written in Python. The script allows users to initialize a list of tasks and manage them interactively through a menu-driven system.

For the original code reference, please see the file named **souce code vityathi.pdf**.

## Features

* **Initial Setup**: Start by declaring how many tasks you want to add initially, and then enter them one by one.


* **Add Task (Option 1)**: Append a new task to your existing list.


* **Update Task (Option 2)**: Search for an existing task by its name and replace it with a new task.


* **Delete Task (Option 3)**: Remove a specific task from your list by typing its name.


* **View Tasks (Option 4)**: Display all current tasks in your list.


* **Error Handling**: The program includes a `try-except` block to catch `ValueError` exceptions, ensuring it handles non-numeric menu inputs without crashing.



## How to Use

1. Run the Python script in your terminal or IDE.
2. Upon seeing `----WELCOME TO THE TASK MANAGEMENT APP----`, enter the total number of tasks you wish to start with.


3. Input the names for each of your initial tasks.


4. Use the number keys `1` through `5` to navigate the interactive menu.


5. Select option `5` to close the program when you are finished.



## Requirements

* Python 3.x (No external libraries required, uses only built-in standard Python functions).
